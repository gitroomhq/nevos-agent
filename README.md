# Nevo's agent plugins

Nevo David's plugins for Cursor, built from [cursor/plugin-template](https://github.com/cursor/plugin-template).

| Plugin | What it does |
| --- | --- |
| [nevos-brain](plugins/nevos-brain) | Nevo's distribution and marketing playbooks, searchable by your agent ([nevo.md](https://nevo.md)) |

- `.cursor-plugin/marketplace.json` lists every plugin
- `plugins/<name>/` holds each one; to add another, see [docs/add-a-plugin.md](docs/add-a-plugin.md)

## Validate

```bash
node scripts/validate-template.mjs
```
