# Nevo's Brain for Cursor

Gives your Cursor agent Nevo David's distribution and marketing playbooks: how he grew Postiz, a bootstrapped SaaS, to millions in ARR.

## What's inside

- **MCP server** `nevos-brain` at `https://mcp.nevo.md/mcp`, with two tools: `search_brain` and `list_sources`
- **Skill** `nevos-brain`, which tells the agent when to search the brain and how to answer from it

The first time the agent uses it, you sign in with your email. It is free.

More at [nevo.md](https://nevo.md).
